# Royal Wedding Invitation Web App (Kerolos & Mera)
## دعوة زفاف إلكترونية ملكية تفاعلية

نسخة طبق الأصل ومطورة بالكامل من دعوة الزفاف الفاخرة على موقع ChungDoi (`https://chungdoi.com/i/kerolos-mera`) بكل تفاصيلها الفنية، التفاعلية، والتصميمية.

---

### ✨ المميزات الرئيسية للموقع (Key Features)

1. **الظرف الملكي التفاعلي وختم الشمع (Interactive 3D Wax Seal & Envelope)**:
   - ظرف أحمر داكن (Burgundy) فاخر مع لمسات مذهبة.
   - ختم الشمع الأحمر التفاعلي (K&M) عند النقر عليه ينبض وينكسر مع صوت واقعي ومؤثرات تناثر الجزيئات الذهبية والبريق (`particle-burst`).
   - انسياب الظرف للأعلى وكشف بطاقة الدعوة بسلاسة فائقة.

2. **الموسيقى الرومانسية الخلفية (Background Romantic Music)**:
   - تشغيل تلقائي فور فتح الظرف مع أغنية *Ordinary - Alex Warren* الأصلية.
   - زر عائم للتحكم بالصوت (تشغيل/إيقاف مؤقت) مع دوران أسطوانة الفينيل وأمواج الصوت.

3. **الهوية البصرية والفنية الفاخرة (Theme: Minimalism Dark Red)**:
   - خلفية ألوان مائية لقصر ملكي (`castle-background.webp`) وزخارف ورود كلاسيكية (`flower2-decoration.webp`).
   - تدرجات العنابي والأحمر القاني والذهبي الملكي (`#721626`, `#8B1E2E`, `#D4AF37`).
   - خطوط طباعية ملكية راقية (`Pinyon Script`, `Playfair Display`, `Cinzel`, `Amiri`).

4. **تفاصيل الإكليل والعائلات (Ceremony & Parents)**:
   - إعلان رسمي بمباركة الآباء: الأستاذ أنور حلمي (Mr. Anwar Helmy) والأستاذ نشأت يوسف (Mr. Nashaat Yosef).
   - صورة البورتريه الرئيسية للعروسين داخل إطار مقوس مذهب.

5. **معرض الصور التفاعلي (High-Resolution Gallery & Lightbox)**:
   - شبكة بطاقات لعرض 6 صور عالية الدقة للعروسين.
   - عارض صور منبثق (Lightbox) بدقة كاملة مع إمكانية التنقل بالأسهم والإغلاق والتقريب.

6. **تاريخ وموعد حفل الاستقبال (Reception & Date)**:
   - الأحد، 30 أغسطس 2026 في تمام الساعة 8:00 مساءً (Girga, Egypt).
   - تقويم تفاعلي لشهر أغسطس 2026 مع إبراز يوم 30 بقلب مذهب نابض.
   - عداد تنازلي حي ومباشر (أيام، ساعات، دقائق، ثواني).
   - أزرار إضافة للتقويم: Google Calendar وتنزيل ملف `.ics` لـ Apple Calendar و Outlook.

7. **موقع الكنيسة والقاعة والخرائط (Venue & Directions)**:
   - كنيسة رئيس الملائكة ميخائيل بجرجا (St. Michael the Archangel Church – Girga).
   - حفل الاستقبال بقاعة القصر الذهبي بجرجا (Golden Palace Hall).
   - خريطة تفاعلية مدمجة + زر توجيه وفتح ملاحة Google Maps بنقرة واحدة.

8. **تأكيد الحضور وسجل التهاني (Interactive RSVP & Wishes Wall)**:
   - نموذج تأكيد الحضور (اسم الضيف، عدد الأفراد، نعم سأحضر / للأسف أعتذر، ملاحظات) مع حفظ محلي في `localStorage`.
   - حائط التهاني التفاعلي: يتيح للضيوف كتابة تهنئة لتظهر فوراً على الشاشة مع قلوب وتاريخ.

9. **دعم كامل للغتين (Bilingual EN / AR)**:
   - زر عائم للتبديل الفوري بين اللغة الإنجليزية والعربية مع دعم اتجاه النصوص (RTL/LTR).

10. **درج التخصيص المباشر (Live Customizer ⚙️)**:
    - يمكنك تغيير أسماء العروسين، الآباء، تاريخ وساعة الزفاف فوراً لتخصيص الدعوة لأي زفاف آخر بنقرة واحدة.

### 🚀 كيفية تشغيل المشروع محلياً (How to Run)

1. **تشغيل فوري ومباشر**:
   - يمكنك ببساطة النقر مرتين (Double Click) على ملف `index.html` ليفتح في أي متصفح ويب.

2. **عبر سيرفر محلي (مفضل لتشغيل الصوت دون قيود أمان المتصفح)**:
   افتح موجه الأوامر (Terminal / PowerShell) داخل المجلد واكتب:
   ```bash
   python -m http.server 3000
   ```
   ثم افتح المتصفح على: `http://localhost:3000`

### 🌐 كيفية النشر على الإنترنت مجاناً (Free Deployment)

- **Vercel**: اسحب المجلد وأفلته في Vercel أو اربطه بمستودع GitHub وقم بعمل Deploy بثوانٍ.
- **GitHub Pages**: ارفع الملفات إلى مستودع GitHub وفعّل GitHub Pages من إعدادات المستودع (Settings -> Pages -> Deploy from branch: main).
- **Netlify**: اسحب المجلد وضعه في Netlify Drop ليعمل موقعك فوراً برابط مباشر مجاني.
